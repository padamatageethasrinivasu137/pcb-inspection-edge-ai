# Project Demonstration

This directory contains demonstration material for the PCB defect inspection system.

## Demonstration Video

The project demonstration video should be linked here when its shareable URL is available.

## Screenshots

Place genuine screenshots of the running application in `screenshots/`.

Suggested captures:

- `application_home.png` — Flask application interface.
- `uploaded_pcb.png` — PCB image selected for inspection.
- `detection_result.png` — annotated detection output.

## Example Images

Place representative input and output examples in `examples/`.

Suggested filenames:

- `sample_input.jpg`
- `sample_output.jpg`

Use images that may legally be redistributed. Avoid publishing private, sensitive or unlicensed dataset material.

## Current Demonstration Scope

The implemented application supports browser-based image uploads, ONNX CPU inference, bounding-box visualization and detection summaries.

An integrated live-camera workflow is not currently implemented.
